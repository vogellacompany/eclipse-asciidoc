AsciiDoc Editor for Eclipse

An AsciiDoc editor for the Eclipse IDE with syntax highlighting, content assist, validation, hyperlinks and an HTML preview, driven by a language server.

Install it in Eclipse with Help > Install New Software, using the update site

https://vogellacompany.github.io/eclipse-asciidoc/

The required LSP4E and TM4E plugins are pulled in from the Eclipse release train and their own update sites.

This site carries the newest build and nothing else. Older versions are not supported: the previous build is dropped when a new one is published, so update rather than pin.
